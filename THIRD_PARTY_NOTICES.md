# Third-party references

opsmesh does not vendor NoneBot2 or OpenAI Agents SDK source code. The framework is an independent implementation inspired by NoneBot2; the OpenAI adapter uses the installed SDK dependency.

- [NoneBot2](https://github.com/nonebot/nonebot2), MIT: architectural reference for plugins, drivers, adapters, matchers and dependency injection.
- [OpenAI Agents SDK](https://github.com/openai/openai-agents-python), MIT: optional runtime dependency and integration reference.

Dependencies retain their respective licenses. If upstream code is copied or modified later, preserve its original copyright and license notices in the relevant files and record the exact source revision here. Architectural resemblance does not imply binary compatibility or endorsement.
