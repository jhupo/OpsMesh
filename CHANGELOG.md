# Changelog

All notable changes to OpsMesh will be documented here.

## 0.1.0 - Unreleased

- Added backend control-plane foundation for workspaces, agents, teams, tasks, runs, workers, runtime spaces, approvals, files, artifacts, operations, and audit trails.
- Added unified marketplace foundations for agents, skills, MCP servers, and plugins.
- Added resource review policy: public resources require review; private workspace resources skip review by default and can be opted into review.
- Renamed public project branding to OpsMesh.
