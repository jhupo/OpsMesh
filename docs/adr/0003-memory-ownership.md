# ADR 0003：默认由平台管理记忆生成

- 状态：采用，2026-10-30。
- 背景：SDK的文件记忆与Session历史独立，自动生成涉及额外模型调用和沙箱关闭时序，必须可计量、授权和重试。
- 决策：modules.memory拥有策略、namespace、生成任务、候选/发布版本与清理；runtime只协调。默认managed_job模式，禁用SDK自动生成并创建可追踪平台任务；sdk_on_close为需要单独验收的可选模式，同一范围不得双重生成。
- 依赖：workspaces提供文件与快照，execution提供环境，usage记录独立费用。生成失败保留旧版本，候选经过校验与CAS后发布。
- 结果：实现复杂度增加，但任务可重试、可观察和独立预算。不会调用SDK私有manager作为稳定公开API；使用公开能力或平台显式工作流完成生成。详见[记忆设计](../design/memory.md)。
