# Frontend 架构

状态：完整上游基线上的 OpsMesh 登录、工作空间/项目选择与个人设置
更新：2026-09-22

## 基线与目录

使用 `satnaing/shadcn-admin` 的 `e16c87f` 源码及 PR #311 的 `95b8f5a` 国际化补丁。
按用户要求保留上游任务、聊天、应用、错误页及示例数据；这些演示数据不是 OpsMesh 业务记录。
采用 React、TypeScript、Vite、TanStack Router/Query、Tailwind 和 shadcn/ui。

`routes -> features -> api/components` 是依赖方向：薄路由负责入口，features 组合产品功能，
api 只消费公共接口，components/ui 保留上游原语。context 管理主题、布局及工作空间/项目选择；
i18n 管理中英双语，styles 保留上游语义主题。Shadcn Space 通过 components.json 注册表导入
源组件，不引入另一套运行时组件库。许可证保留在 frontend/licenses。

## 登录与外壳

未登录访问受保护路由跳转到 /sign-in，并保留站内 redirect。登录调用 /auth/login，成功后
加载 /auth/me，令牌仅存入标签页 sessionStorage。401 清除会话；退出撤销当前令牌。
label-06 承载 Email、Password 浮动标签、聚焦底线和错误红线；无注册、找回密码、第三方登录、
协议或解释段落。标签按要求固定为英文，按钮随中英语言切换。

外壳保留上游侧栏，底部用户信息与设置分组已移除。公共 AuthenticatedLayout 只挂载一个
Header，固定占据顶部区域，下面的内容容器独立滚动并随路由切换；页面不再创建标题栏。
Header 底部带分隔线，包含侧栏开关、分隔线、
All Projects、主题、语言、通知、消息及真实用户菜单。移除 Dashboard 顶部重复导航。
主题直接切换，语言仅中英。工作空间/项目选择及通知收件箱通过公共 API 加载；
其余模板演示不会据此变成已接入后端的产品功能。

## 设置与合同

| 设置 | 状态 |
| --- | --- |
| 姓名 | PATCH /auth/me，成功回写当前用户缓存 |
| 邮箱 | 当前用户真实邮箱，只读；变更/验证流程尚未接入 |
| 简介 | 禁用预留字段，无本地伪保存 |
| 修改密码 | PUT /auth/password，成功后遵循后端令牌撤销合同返回登录 |
| 通知范围、任务进度/审批/账号安全邮件 | 禁用预留字段，尚无偏好保存接口 |
| 调试面板 | 仅开发环境、平台超级管理员可开启；默认关闭 |

账户设置合并到个人资料；移除生日、网址、外观及独立账户页。设置使用注册表 tabs-06 的
竖向动画导航，窄屏按组件结构排列为横向，保留 shadcn Tabs 的键盘交互；用户菜单是设置入口。
预留字段不能静默写 localStorage、模拟请求或
展示保存成功。后端支持后再补齐公开合同、加载与保存流程。

/auth/me 返回真实 platform_admin 布尔值。普通工作空间管理员不等于平台超级管理员；
前端不会按用户名或其他权限探测推断身份。Router 和 Query 调试面板仅挂在受保护布局内，
只有 DEV 且 platform_admin 为 true 且用户开启显示才加载；登录页绝不挂载。
本地存储仅保留每个用户的显示偏好，不作为授权依据。安装版 API 尚未包含该字段时保持隐藏，
需后续发布更新，不能描述为服务器已启用。
