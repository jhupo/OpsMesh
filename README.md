# OpsMesh

## 项目目标

OpsMesh 是基础 Agent 编排平台，提供服务端、独立 Python SDK 和 Linux 部署工具，不包含前端。

- 用户组合 Agent、工具、MCP 和 Skill，创建、发布并运行自己的专家或团队。
- 平台提供身份、模型接入、数量额度、任务运行、私有会话、文件资源和隔离执行等基础功能。
- 多用户各自拥有独立会话和历史，按明确授权使用共享能力与资源。
- 知识库、记忆策略、业务流程、厂商协议和市场等定制功能由独立扩展包实现；支持从可配置的 GitHub Releases 获取包或本地导入。
