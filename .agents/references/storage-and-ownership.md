# 存储、所有权与隔离

## 所有者与入口

`src/opsmesh/resources/layout.py` 定义宿主存储命名空间；`storage/base.py` 与 `storage/contracts.py` 定义文件接口；`storage/local.py` 实现本地存储；`directories` 管理用户目录及显式共享。

## 不变量

- 构造 StorageLayout 只解析路径，不创建资源、不读全局配置、不打开数据库。实际存储与权限由调用模块拥有。
- directories、packages、history、gateway/media、plugin-packages、plugins 分别存放目录、资源包、会话历史、通道媒体、插件包与插件数据。不可将发布物和用户数据混存进源码目录。
- 对象 ID、用户所有权和授权先校验，再解析磁盘路径；不信任请求中的绝对路径、父目录跳转或符号链接逃逸。
- 文件存储适配器不负责 Agent/编排生命周期，也不能绕过目录访问服务直接授权。
- API、Worker、Docker daemon 必须指向相同的持久绝对路径；容器内路径映射错误不能通过宽松回退修复。
- 密钥、提示词、工具参数、模型输出、MCP 凭据与会话内容不能进入普通日志、未经加密的历史或审计摘要。加密 key_id 和所需旧密钥的可解析性属于恢复合同。
- 审计与业务写入保持事务一致；禁止对未授权用户返回资源是否存在的私有信息。

## 改动检查点

核对目录共享、撤销权限、路径逃逸、传输大小限制、原子写入、加密及备份恢复。保留用户已有目录、环境和备份；本地代码清理不是存储数据清理授权。
