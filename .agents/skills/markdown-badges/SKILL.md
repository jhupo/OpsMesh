# Markdown Badges

Use the catalog from the official repository:
https://github.com/ileriayo/markdown-badges

Apply this skill only to Markdown documentation and README surfaces. It is not a
source of runtime UI components or image assets for the web application.

- Match the repository's existing badge style and keep a small, meaningful set.
- Prefer badges whose link target is authoritative and stable: the repository,
  release page, package registry, license, CI workflow, or documentation site.
- Keep badge alt text descriptive and links usable in plain Markdown.
- Do not add decorative badges, popularity claims, or badges that require secrets
  or an unverified external service.
- Preserve existing README structure and update only the requested documentation
  surface.

The wrapper tracks the public repository at commit
`19da5719a6a676ead9d35083c9e83a7b0413d773`; consult its README for the current
badge catalog and syntax instead of copying a stale list into this skill.
