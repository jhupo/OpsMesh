# 文档覆盖清单

- 入口：公开导出、路由、CLI、插件 setup 和打包命令是否存在？
- 配置：环境变量、默认值、约束和密钥解析是否与当前 Settings/配置模型一致？
- 所有权：配置、实例、Session、Run、环境、插件数据和目录是否分清？
- 生命周期：安装、启用、热更新、审批、重试、取消、关闭和删除是否描述准确？
- 版本：原生 SDK、锁文件、迁移历史、发布版本和不可变插件包是否区分？
- 示例：JSON 字段符合当前模型；编排先发布、再创建绑定实例、再提交 Run。
- 覆盖：静态检查、真实基础设施测试、模型调用和未验证项目分别说明。
- 链接：相对路径能解析到现存文件；移除文件的引用同步更新。

只记录长期合同，不把一次测试结果、临时任务状态或未来计划写成已验证行为。
